# 可直接复制的排版 Prompt

以下提示词根据多次学术文档排版需求**归纳改写**，并非逐字引用某位用户的聊天记录。使用时，请先让 ChatGPT 阅读仓库中的 `SKILL.md`，再复制对应 Prompt。方括号中的内容由使用者按实际情况替换。

## 1. 万能版本：先方案，再制作

> 我上传了这次需要排版的资料。请先完整阅读 `SKILL.md` 及全部附件，确认有哪些正式模板、文字、图片、表格、公式与参考文献。排版要正式、清晰、美观，有学术报告的质感，但不要花哨。优先保留我的原始内容、数据和结论，只修正明显错别字、病句、编号或排版问题。先把影响成品的必要问题一次性问完，再给出具体排版方案（目录与章节层级、字体、页面、图表、公式、文献、封面和交付格式）；**等我确认方案后再生成**。生成后请真实编译 PDF，逐页检查并修复图表错位、大片留白、越界、裁切、乱码和编号引用错误。最后给我 PDF 与可再次编译的完整 LaTeX ZIP，不要只贴部分源码。

## 2. Word / PDF 转 LaTeX：严格模板复刻

> 我上传了原始 Word/PDF 和参考模板。[参考模板名称] 是本次排版的第一视觉标准。请尽量一比一复刻其封面、页面规格、页眉页脚、标题层级、字体字号、目录、章节起始方式及图表题注，不要自行设计另外一套风格。原文内容基本保持不变，只允许修复明显标点、病句、编号和格式。原有摘要、关键词、图片、表格、公式和参考文献不得自行删除或改写。图片要提取成独立资源；能规范转换的表格使用三线表；数学表达恢复真正的 LaTeX 公式；参考文献可整理到 `references.bib`，但不能编造书目信息。先向我展示复刻方案，待我确认后制作。请提供可在 Windows + VS Code + TeX Live 环境中继续编译的完整工程及 PDF，并进行逐页视觉检查。

## 3. 课程实验报告：整洁、易读、无大块留白

> 请根据我上传的实验要求、实验过程、程序输出和图片，制作一份正式的课程实验报告。正文层级要清楚，术语和公式规范，图片与对应的实验步骤或分析尽量放在同一页或相邻位置。表格优先黑白三线表；图片必须保持清晰和原始比例，图例、坐标轴和文字不能太小，也不能遮住数据。请特别检查表格下方的大面积留白、图题孤立、图片挤在一起、标题在页末等常见问题。结果必须来自我提供的真实数据，不得自行编造。没有课程模板时可以提出一套简洁的工科论文风格，但要先给我审核排版方案。

## 4. 科研论文：优先遵循期刊模板

> 请按照我上传的 [IEEE/Elsevier/其他期刊] 官方 LaTeX 模板排版论文，严格遵守模板的单双栏、字号、参考文献、图表格式和版面规则，不要为了美观擅改官方模板。保留公式、数据、图、参考文献与技术结论。重点检查双栏图宽、图中文字可读性、图片边缘留白、长公式、表格越界、交叉引用和 bibliography。对于 Fig.[编号] 等难排版图，可以比较几种合理宽度或排布方案，实际编译并渲染后再选择，不要凭猜测裁图。所有提交的 LaTeX/Bib/图表资源必须齐全。请先给排版方案，待我确认后再改。

## 5. 竞赛 / 技术报告：评委阅读路径清晰

> 这是一份面向 [竞赛评委/项目答辩/工程评审] 的技术报告，已有的技术内容、实测结果和截图应充分保留。请按照附件中的提交要求与参考样张排版，重点突出方案架构、方法、实现细节、实验过程与结果之间的清楚对应。可以规范章节、编号、三线表与流程图，但不要重写技术事实或添加未经验证的性能指标。图文关联要自然，流程图箭头方向和模块拓扑必须准确；如横向布局过宽，可提出双行蛇形流程图等备选，确认后实施。最终输出 PDF 与完整 LaTeX 工程，附编译方法。

## 6. 图表局部返修：只修问题，不牵连全文

> 请重点修复第 [X] 页的 [图/表/公式]：[具体问题，例如图例挡住曲线、两幅图太挤、表格底部空白过大]。保留数据、比例和图意，不要随意改动其他章节。先定位造成问题的 LaTeX 源因，再提出合理排版调整，例如移动图例、改变 `\textwidth` 比例、调整子图排列、裁去**不包含信息**的空白边缘、修改浮动体参数。请分别编译检查候选效果，选择最清晰自然的方案；返修后至少复查目标页和前后页，并说明改动了什么。

## 7. 流程图与图文：内容优先于炫技

> 请把附件中的流程关系制作为清晰、正式的 LaTeX/TikZ 或矢量流程图，风格以黑白为主，箭头的方向、连接点、回路和分支含义必须和原始算法一致。布局可以采用单行、双行或蛇形，但不能为了节省空间改变流程语义。图内文字不要过小，图例尽量放在不遮挡内容的位置。如我提供了真实设备图片，应保持图文对应，不能使用生成的虚假实物图替换。请在实际 PDF 中检查线条、公式符号、字体和裁边是否正常。

## 8. 编译结束后的强制验收

> 请不要只回复“编译成功”。把最终 PDF 的每一页渲染出来进行检查，重点检查：是否有异常空白页/大片留白；标题、图题、表题、页码是否孤立或错位；表格是否超宽/断裂；图片是否被裁切或变形；公式是否变成可见的 LaTeX 源码；中文字符是否乱码；图例、坐标轴、单位是否清楚；引用是否出现问号。对发现的问题请在源码中定位并修复，然后重新编译并复查。最终告诉我实际检查了几页、是否有未解决问题，并给出 PDF 和可编译 ZIP。

## 9. 极简 Prompt（适合给同学转发）

> 请先读我上传的 `SKILL.md`。你是一名专业的学术 LaTeX 排版助手：**有模板严格复刻，无模板采用克制的学术排版；内容与数据保真，图表公式规范，文字层级清楚；先给方案等我确认，再制作；实际编译后逐页检查 PDF，修好留白、错位、裁切和溢出；最后交付 PDF + 完整 LaTeX 工程 ZIP。**

## 组合建议

第一次制作：`1 + 文档对应的 2/3/4/5`；局部修改：`6 或 7`；定稿前：`8`。不必把所有提示词一次性全贴给模型，也不必重复已有的任务要求。

## 选句摘录：保持使用者习惯的表达方式

这些是过去排版约束的**短句化整理**，用来保留自然、直接的指令口吻；不是聊天记录的逐字转录，也不是每个项目都要同时遵守的绝对要求：

- “尽量一比一复刻我提供的模板，不要自己换一套样式。”
- “排版现代一点，但要保持正式工科论文的感觉。”
- “流程图黑白，表格尽量用黑白三线表。”
- “图片清晰，图和对应文字放在一起，不要有大块空白。”
- “先把要求问清楚，给我看方案，确定以后再制作。”
- “生成 PDF 后要真正逐页看，不是编译成功就算完成。”
- “给我完整工程，能在自己的电脑上继续修改编译。”

注意：模板中若规定彩色流程图、网格表或特殊字体，应遵循模板而不是上述场景性偏好。
