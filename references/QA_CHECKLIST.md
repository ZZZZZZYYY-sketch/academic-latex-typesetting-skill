# PDF 终检清单

> 这个清单用于**实际已生成的 PDF**。不要仅根据源码推断 PDF 正常。

## A. 内容完整性

- [ ] 标题、作者信息、原文段落、摘要和关键词按用户确认方案保留，没有无故删节
- [ ] 图片、实验数据、代码结果、公式和结论未被伪造、改写或遗漏
- [ ] 新增的解释性材料已获用户批准，并与原文清晰区分
- [ ] 引用与参考文献能追溯到可靠来源或用户提供资料

## B. 编译与文件

- [ ] 使用目标模板要求的编译引擎成功编译
- [ ] `.log` 中没有未处理的致命错误、缺失文件、未定义交叉引用
- [ ] Citation / Biber / BibTeX 处理完成；没有 `??` / `[?]` 占位
- [ ] 已人工审视 Overfull/Underfull 警告；严重版式告警已修复
- [ ] ZIP 中包含 main.tex、章节文件、图片、必要 bib / class / style、编译说明
- [ ] 在干净目录试编译或至少验证所有引用路径可用；没有无关缓存文件

## C. 逐页视觉检查（每页都看）

- [ ] 封面、目录、正文、参考文献、附录顺序正常；页码无错乱
- [ ] 标题不孤立在页尾；无异常整页空白和不必要的大面积空白
- [ ] 图片无裁切关键内容、变形、重叠或低分辨率失真
- [ ] 图中文字、图例、坐标轴、单位足够清楚；图题在正确位置
- [ ] 每张表的表头可读，无越界、过密、错误断行或残缺
- [ ] 长表跨页时结构与表头正确；表题不和表格分离
- [ ] 公式确实渲染为数学字形，没有 `_`、`\Delta` 等不应暴露的源码
- [ ] 中文字符完整、没有乱码/方框/异常字体替代
- [ ] 参考文献、脚注、超链接/引用、图号/表号/公式号均正常
- [ ] 正文和相应图表相邻，分页节奏自然，没有一行正文占一整页

## D. 修复闭环与交付说明

- [ ] 发现的问题已针对 LaTeX 根因修复，而不是仅用负间距掩盖
- [ ] 修改后实际重新编译、重新渲染；复查受影响页及前后页
- [ ] 明确记录实际验收了几页、使用的编译引擎、尚存问题
- [ ] 只有**确实执行**以上动作后，才能使用“已逐页检查通过”等措辞

## 可选的自动辅助命令

```bash
latexmk -xelatex -interaction=nonstopmode -file-line-error -halt-on-error main.tex
python scripts/check_latex_log.py main.log
python scripts/render_pages.py main.pdf --out-dir pdf_pages --dpi 160
```

自动日志诊断与逐页渲染都是辅助，**无法独立判断**图例是否遮住数据、视觉节奏是否自然或事实是否正确；这些必须再由人或具有图像查看能力的模型审查。
