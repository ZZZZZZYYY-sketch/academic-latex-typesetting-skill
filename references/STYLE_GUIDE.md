# 排版风格与细节规范（默认规则，不覆盖官方模板）

## 1. 先确定视觉基准

| 场景 | 视觉基准 | 要避免的情况 |
|---|---|---|
| 学校课程报告 | 官方课程模板；缺失时采用正式工科报告风 | 华而不实封面、标题层次混乱 |
| 实验报告 / 课程设计 | 清楚的过程—结果—分析结构；图文紧邻 | 数据图字太小、漂浮到无关章节 |
| 技术 / 竞赛报告 | 主线明确、结果可追踪、图表服务论证 | 堆砌图表、为了视觉冲击随意加配色 |
| IEEE / 其他科研论文 | 官方类文件与作者指南 | 擅改两栏参数、字号、脚注和图题格式 |
| 样张严格复刻 | 用户给定样张 | 另起炉灶、贴整张图伪装可编辑排版 |

## 2. 无模板时的建议（需要在方案中确认）

- 页面可先建议 A4，单面与双面依需求确定；页边距和行距以阅读、装订和页数要求为依据，不将一套固定数值强制使用在所有任务上。
- 中文正文优先宋体或合法的宋体兼容字体；标题使用黑体，西文/数学字体优先 Times New Roman 或近似兼容字体。部署平台字库不同，必须检查实际编译结果；不得默默把“Times New Roman”替换到明显不同的视觉风格却仍声称完全一致。
- 标题一般不超过 3 个正文层级；合理设置段前段后，不靠手动空行营造间距。长报告可自动目录；短实验报告不必机械添加空洞目录。
- 默认黑白或低饱和配色。流程图和正式科研图要优先保证黑白打印可读性；除非用户特别要求，否则图像颜色应表达信息而非装饰。
- 封面仅包含用户要求的信息；姓名、学号、院系、竞赛编号等不得臆造。

## 3. 图与表

**图片：**
- 采用原图/高分辨率图；按比例缩放，必要时剪裁多余空白，但不能剪掉图例、箭头、数据或注释。
- 同类对比图在字号仍可读时才并排；否则一行一图。图例可能放在图右侧、下方或图外，但需全篇风格统一。
- 图题在图下；引用用 `\label` / `\ref`。多个子图需要 `(a)/(b)` 标识时，依模板和读者理解选择。
- 可用 `\includegraphics[width=0.95\linewidth]{...}` 作为初始尝试，**不是不可调整的常量**。针对图2、图3等独立调整，要实际检查。
- 不使用整张 PDF 截图当作公式、表格、流程图的替代品（源文件不可编辑且清晰度通常较差），除非用户明确需要原样嵌图。

**表格：**
- 推荐 `booktabs` 的 `\toprule`、`\midrule`、`\bottomrule`，不画繁密竖线；但官方样稿采用网格表时优先样稿。
- 对数字、百分比、单位、科学计数法使用一致格式；单位放表头而不是默默省略。
- 宽表可考虑缩小列间距、文字换行、横向页、跨栏或附录；尽量不要整体缩成无法阅读的小字。
- 对超过一页的表考虑 `longtable`，不可只依赖 `[H]` 把表强塞进当前页。

## 4. 公式、引用和参考文献

- 使用 `equation`、`align`、`cases`、`gather` 等语义正确的数学环境，不直接拼接数学命令为普通正文。
- `\eqref` 的编号、变量斜体、上下标与单位格式需一致；重要公式不应被页面裁掉，双栏长公式尽量在模板许可范围内分行。
- 文献条目必须来自提供的原文献、可靠检索或用户认可的参考信息，不得凭记忆补全不存在的作者/DOI。
- 模板若要求 BibTeX、Biber、GB/T 7714 或 IEEEtran，必须按要求处理，不将工具默认 `numeric` 强加到目标稿件。

## 5. 为什么不在 Skill 中硬编码一套字号

真实项目可能要求宋体小四、1.25 倍行距、特定页眉或奇数页开章，也可能要求期刊双栏 10pt。它们都是**具体任务要求**，并不能同时成立。Skill 负责在用户与模板约束内给出最合适的排版策略，并确保全篇一致和最终视觉质量。

## 6. 典型 LaTeX 失误及优先修法

| 实际问题 | 常见原因 | 优先修法 |
|---|---|---|
| 表格之后大块留白 | 浮动体不能放入当前页、强制定位、分页指令 | 重新审视表格尺寸与放置策略、浮动参数、分页 |
| 图超出页边 | 固定尺寸过大、误用 `\textwidth`/`\linewidth`、双栏不匹配 | 按所在栏宽设置并编译验证 |
| 图例遮住数据 | 图自身边距与图例位置不合理 | 从源图移图例、调整布局与字号，慎用裁剪 |
| 公式展示出 `\Delta` 或 `_` | 数学符号未进入数学环境、转义错误 | 修数学环境并查看 PDF 字形 |
| 中文方块或字体错配 | 字体缺失、fallback、错误编译引擎 | 改用可用字体/正确引擎，复查嵌入字形 |
| “参考文献 ?” | 未编译完整、bib 配置错误、label 拼写错 | 处理 BibTeX/Biber、重编译、检查日志 |
